# PatientCurve Revenue Diagnostic

A single-page sales-call tool built from the *Dental Clinic Revenue Growth Strategy*. Open `index.html` in any browser (no build step) and walk the clinic through eight steps:

1. **Clinic & goal**: current vs desired revenue, the gap
2. **Patient funnel**: enquiry → appointment → consultation → plan accepted → start; finds the biggest leak in ₹/month
3. **Existing patients**: revenue sitting in the database (reactivation, recall, pending treatments, referrals)
4. **High-value treatments**: acceptance and mix by treatment
5. **Capacity**: chair utilisation and the "grow demand vs grow revenue per patient" rule
6. **Current systems**: none / manual / systemised for each part of the journey
7. **Opportunity map**: every opportunity sized in ₹ and ranked on revenue, confidence, cost, speed, difficulty and capacity
8. **Decision & next call**: recommended intervention, Call 2 storyline and a copyable call summary

Each step lists the questions to ask and has a notes box. Data is saved in the browser (localStorage) per clinic; use **Export / Import** to move a clinic between devices or into a CRM.
